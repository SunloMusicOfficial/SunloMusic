## ✨ Features

- ⚡ **Ultra-Fast Streaming:** Direct yt-dlp extraction with zero lag.
- 🎨 **Premium UI:** Beautiful inline keyboards, customized thumbnails.
- 🧩 **Plugin System:** Add new features just by dropping a `.py` file in `plugins/`.
- 🔐 **Auth System:** Protect your bot from unauthorized group usage.
- 🌍 **Multi-Language Support:** Hindi and English built-in.
- 🛡 **Sudo & Admin Controls:** Advanced permission handling.
- 📻 **Live Radio:** Stream live radio URLs.
